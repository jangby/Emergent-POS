# KasirPintar AI - PRD

Mobile-first Web POS + Inventory app for Indonesian UMKM.

## Core features (MVP)
- JWT auth (login/register); owner seeded as robaya05@gmail.com
- POS: product grid, category filter, cart, cash + QRIS payment, receipt
- Web Bluetooth ESC/POS thermal printer + PDF fallback
- Inventory CRUD + low stock alerts
- Transactions history + re-print
- Analytics dashboard (revenue/profit charts, top products)
- AI Vision OCR receipt scanner (Gemini 3 Flash)
- AI Business Insights (Gemini 3 Flash)
- Midtrans QRIS integration (settings-configurable)
- Dark/light theme toggle
- Sample Indonesian retail products pre-seeded
